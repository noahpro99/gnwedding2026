# Public assets

Drop these files here. Names referenced by the app:

- **`hug.png`** — full-bleed photo of you two used as the homepage hero.
  Displayed at full viewport height with a dark overlay for text contrast,
  so use a high-resolution image with the subjects roughly centered.
- **`card-frame.png`** — decorative invitation border with a **transparent
  center**. Used by `/save-the-date` and `/invite/$id`. Aspect ratio ~3:4
  works best.
- `favicon.ico` (optional)
- `og.jpg` (optional, ~1200x630) — social share preview.
