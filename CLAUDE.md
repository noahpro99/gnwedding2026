# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
bun run dev        # dev server with SSR + HMR on port 3000
bun run build      # production build into dist/
bun run start      # run production server (bun serve.ts) on port 3000
bun run typecheck  # TypeScript type check (no emit)
bun run db:init    # initialize SQLite schema and insert demo invite
```

No lint or test runner is configured — typecheck is the only automated check.

## Architecture

**Stack**: Bun + React 19 + TanStack Start (SSR) + TanStack Router (file-based) + Tailwind CSS v4 + SQLite (`bun:sqlite`)

**Routing**: `src/routes/` maps 1:1 to pages. `src/routeTree.gen.ts` is auto-generated by the TanStack Vite plugin — never edit it manually. Path alias `~/` resolves to `src/`.

**Server functions**: Form submissions (RSVP, shuttle requests, registry claims) use TanStack's `createServerFn` in `src/server/rsvp.ts` and `src/server/registry.ts`. There is no separate REST API layer — server functions run in the same Bun process and access SQLite directly.

**Database**: `src/server/db.ts` opens the SQLite file (default `./data/wedding.sqlite`, overridden by `DB_PATH`), enables WAL mode + foreign keys, and bootstraps the schema on first run. Tables: `invites`, `rsvps`, `transport_requests`, `registry_claims`.

**Invite system**:
- `/save-the-date` — generic shareable card
- `/invite/$id` — personalized per-household, loads from the `invites` table, enforces `party_size_max`

**Guest list**: `src/server/guests.ts` is auto-generated from a CSV spreadsheet via `src/server/guests-gen.ts`. Edit the spreadsheet and re-run the generator rather than editing `guests.ts` directly.

**Styling**: Custom Tailwind color palette defined in `src/styles.css` (cream, parchment, burgundy, rust, olive, gold, etc.). Use only these named colors to stay on-brand.

**Production server**: `serve.ts` handles both static asset serving and SSR in a single Bun HTTP server. Docker uses a multi-stage build; the runtime container runs `bun serve.ts` on port 3000 behind Traefik on the `noahpi` Raspberry Pi host.

**Deployment**: Push to `main` → GitHub Actions → SSH to `noahpi` → `docker build` + `docker compose up`. Secrets required: `SSH_HOST`, `SSH_USERNAME`, `SSH_PRIVATE_KEY`. The site is hosted at `gnwedding2026.com` (apex only, no www). SQLite persists via a volume mapped to `~/gnwedding-data/wedding.sqlite` on the host.
